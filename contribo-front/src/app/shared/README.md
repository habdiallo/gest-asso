# Éléments réutilisés

Placer ici uniquement des composants UI, pipes, directives ou utilitaires neutres
utilisés par plusieurs fonctionnalités. Importer par `@shared/*`. Aucun appel API
métier, état de feature ou dépendance vers `features/` ; pas de dossiers vides ni
de composant transverse tant qu'un usage partagé n'existe pas.
