# Polices locales

Les fichiers WOFF2 sont servis depuis l'origine de l'application afin que le
rendu ne dépende pas de Google Fonts et reste compatible avec `font-src 'self'`.

- Bebas Neue 400 : `OFL-bebas-neue.txt`
- Outfit variable 300-600 : `OFL-outfit.txt`
- Space Grotesk variable 400-600 : `OFL-space-grotesk.txt`

Sources des fichiers : Google Fonts, avec les URLs `fonts.gstatic.com` utilisées
par la feuille CSS du 3 octobre 2026. Les trois familles sont distribuées sous
la licence SIL Open Font License, dont une copie est conservée avec les assets.
