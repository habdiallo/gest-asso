# Proposition

## Pourquoi

La navigation mobile actuelle expose trop de destinations dans la barre basse et peut laisser l'utilisateur sans retour contextuel depuis certains écrans secondaires. Le Native Design défini pour Contribo regroupe les destinations principales dans une barre mobile stable et réserve les réglages ou espaces secondaires à l'écran Plus.

## Changements

- Regrouper la navigation mobile dans Accueil, Membres, Cotisations, Cagnottes et Plus pour les rôles de gestion.
- Conserver uniquement Accueil et Plus pour le rôle Membre, avec l'espace personnel accessible depuis Plus.
- Ajouter l'écran Plus avec les destinations existantes selon le rôle, sans créer d'action métier nouvelle ni dupliquer Mon accès.
- Ajouter un retour explicite vers le contexte précédent depuis les écrans ouverts par Plus.
- Conserver le bouton de thème près du profil comme action indépendante.
- Inclure la maquette Native Design déjà produite pour garder une référence visuelle cohérente.

## Hors périmètre

- Aucun changement de permissions ou de règles métier.
- Aucun changement de contrat API.
- Aucun changement de navigation desktop.
